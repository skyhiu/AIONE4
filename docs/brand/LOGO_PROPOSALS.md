# AIONE logo proposals (B-5)

Status: **proposal** (alpha.3). The user chooses; if none fits, the user supplies the old logo.
Not used by the app yet. Made by `tools/brand/make_logos.py`; the files are delivered with the
handoff (not in the repository):
- `AIONE_logo_<A|B|C>_<name>_on-dark.svg` / `_on-light.svg`: the full logo, mark above the name;
- `AIONE_mark_…svg`: the mark alone;
- PNG previews of each logo on black and on white.

The name "AIONE" is drawn as outlines from fonts bundled in `assets/fonts` (SIL OFL 1.1; using
glyph outlines in artwork is allowed by the OFL), so the SVGs need no installed font.

| | Mark | Name font | Idea |
|---|---|---|---|
| **A – Orbit** | a ring that is almost closed, with one accent dot in the opening | Quicksand 600 | Everything in one place, and the one thing you pick. Calm, round, friendly. |
| **B – Focus** | two rounded corner brackets framing an accent dot | Figtree 600 | Like the selection on a console screen: the game you have picked. |
| **C – Tile** | a rounded tile holding a smaller, accent-coloured tile | Nunito 700 | The game you are about to start, inside your library. |

**Originality (A12):** no console maker's shapes, letters or marks. In particular there are none of:
- a split controller rectangle;
- the PlayStation button shapes;
- an X in a sphere;
- a pill outline;
- a four-square grid.

**Colours:**

| Use | Ink | Accent |
|---|---|---|
| On black | `#ECEEF1` (contrast 18.1 : 1) | `#4FC3E8` (10.3 : 1) |
| On white | `#15171B` (17.9 : 1) | `#127FA6` (4.6 : 1) |

Every mark also works in one colour (ink only).
